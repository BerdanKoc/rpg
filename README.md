# Choix de GitHub Actions pour notre projet RPG

## Avantages

- **Intégration native avec GitHub**  
  GitHub Actions est directement intégré à GitHub, ce qui facilite l’automatisation des workflows sans outils externes supplémentaires.

- **Automatisation simplifiée**  
  Chaque commit peut automatiquement déclencher des tests unitaires, garantissant une validation continue de notre code, sans nécessiter de configurations complexes.

- **Gratuit pour les projets publics**  
  Pour notre dépôt public, GitHub Actions est entièrement gratuit, ce qui en fait une solution économique et parfaitement adaptée à nos besoins actuels.

## Inconvénients

- **Temps d’exécution parfois longs**  
  Les builds peuvent prendre plus de temps que prévu en raison de la charge sur les serveurs partagés, ce qui ralentit le retour d’informations sur les tests.

- **Dépendance à GitHub**  
  L’utilisation de GitHub Actions est étroitement liée à GitHub. Si nous décidions de migrer vers une autre plateforme, cela compliquerait l’adaptation de nos workflows actuels.
